## Key Decisions

1. **Async Infrastructure:** Add `RunGitAsync` alongside sync `RunGit` (non-breaking). Default 120s timeout. `CancellationToken` for process cancellation.
2. **Service Layer:** `GitResult` record replaces tuples. `IProgress<string>` for stderr streaming. Async worktree methods + `FetchPrRefAsync` overloads.
3. **UI UX:** Overlay marquee progress panel, `System.Windows.Forms.Timer` for elapsed time, Cancel button. All 4 creation modes async via `await Task.Run()`.
4. **Naming:** 10 user-facing strings renamed ("Workspace" → "Worktree"). Internal code identifiers unchanged (future cleanup).
